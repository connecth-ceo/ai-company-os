# 회사 맥락 통합 검색

## 목적

대표와 AI 업무가 저장된 기억, 유효한 대표 결정, 축적된 지식을 한 번에 찾을 수 있는 V1 검색
기반이다. 외부 검색, 임베딩 생성, 모델 호출 없이 로컬 데이터베이스의 최근 후보를 결정론적으로
평가하므로 검색 자체에는 AI 비용이 들지 않는다.

## API

`GET /api/v1/context/search`

| 파라미터 | 기본값 | 설명 |
|---|---:|---|
| `q` | 필수 | 2~200자의 검색어 |
| `type` | 전체 | `memory`, `decision`, `knowledge`; 반복 지정 가능 |
| `effective_decisions_only` | `true` | 활성·효력 발생·미만료 결정만 검색 |
| `limit` | 20 | 최대 100개 반환 |

응답은 통합 점수 내림차순으로 정렬하며 각 항목에 종류, ID, 제목, 검색어 주변 발췌문, 점수,
생성시각, 안전한 메타데이터를 포함한다.

## 검색 규칙

- 정확한 전체 검색어가 제목에 있으면 가장 높은 가중치를 준다.
- 제목의 개별 단어 일치가 본문 일치보다 높은 가중치를 받는다.
- 모든 검색 단어가 제목과 본문 조합에 존재하면 추가 점수를 준다.
- 점수가 같으면 최신 항목을 먼저 표시한다.
- 현재 단계는 유형별 최근 300개 후보를 평가한다.

## 안전 경계

- 모든 후보 조회는 기존 tenant 조건을 먼저 적용한다.
- 기본 검색은 실제 AI 맥락에 반영되는 유효한 대표 결정만 포함한다.
- 검색은 읽기 전용이며 감사 대상 외부 행동을 만들지 않는다.
- API key, system prompt, output schema, 비밀 환경변수는 검색 대상이 아니다.
- pgvector/임베딩 기반 의미 검색은 평가셋과 인프라가 준비된 후 별도 단계로 추가한다.

## CEO Desk

회사 맥락 영역의 검색창에서 기억·대표 결정·지식을 함께 검색한다. 결과는 HTML escape 후
표시하며 저장 데이터나 결정 상태를 변경하지 않는다.
