# Goal → Project → Task 전략 계층

## 목적

회사의 장기·중기 목표를 실행 프로젝트와 개별 업무에 연결한다. 이 단계는 내부 계획 데이터를
정리할 뿐 AI 실행, 외부 발송, 결제, 삭제 또는 배포를 자동으로 시작하지 않는다.

## 데이터 구조

- `Goal`: 목표명, 설명, 성공 기준, 책임자, 목표일, 상태를 저장한다.
- `Project.goal_id`: 선택적인 상위 목표 연결이다. 기존 프로젝트는 `null` 상태로 그대로 유지된다.
- `Task.project_id`: 기존 방식 그대로 프로젝트에 연결된다.
- 최종 계층은 `Goal → Project → Task → Child Task`이다.

## API

- `POST /api/v1/goals`: 목표 생성
- `GET /api/v1/goals`: 최근 목표 목록. `status` 필터를 선택적으로 지원한다.
- `GET /api/v1/goals/{goal_id}`: 목표 상세
- `POST /api/v1/projects`: 선택적 `goal_id`를 검증한 뒤 프로젝트 생성
- `GET /api/v1/projects?goal_id=...`: 한 목표의 프로젝트 목록

## 안전 경계

- 모든 조회와 연결 검증은 `X-Tenant-ID`의 현재 회사 범위 안에서만 수행한다.
- 다른 회사 목표는 존재하지 않는 것처럼 `404`로 처리한다.
- 목표 생성과 프로젝트 연결은 감사 이벤트에 기록한다.
- 기존 Goal 없는 Project 요청과 Project 없는 Task 요청은 계속 허용한다.
- 이 기능 자체는 토큰을 사용하거나 AI 작업을 실행하지 않는다.

## CEO Desk

목표 카드에서 성공 기준, 책임자, 목표일, 프로젝트 수, 완료 업무 수를 본다. 프로젝트 생성 시
상위 목표를 선택하면 프로젝트 카드에도 연결 목표가 표시된다.
