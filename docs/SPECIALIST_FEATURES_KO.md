# AI Company OS V0.5 전문 기능

## 구현 범위

V0.4 제어 흐름과 Phase 1 `AgentRuntime`·`AgentDefinition`·`Registry` 경계를 유지하면서,
명시적으로 요청한 업무에만 전문 에이전트를 추가했다.

- 데일리 브리핑: 데이터베이스의 최근 업무와 승인 상태를 읽어 요약한다.
- Marketing Agent: 조사·전략 자료를 바탕으로 타깃, 포지셔닝, 메시지, 채널, CTA,
  성과지표를 포함한 초안을 만든다.
- Legal Risk Review Agent: 관할, 개인정보, 계약, 지식재산, 광고·표시 관련 위험과
  확인이 필요한 사실을 예비 검토한다.

## Telegram 사용법

```text
/briefing
/marketing 신제품의 인스타그램 소개문과 핵심 메시지를 만들어줘
/legal 신규 서비스 개인정보 처리 흐름의 위험을 검토해줘
```

`/마케팅`, `/법률`, `/브리핑` 한글 명령도 사용할 수 있다. 명령어만 보내고 내용이 없으면
요청 내용을 추가하라는 안내를 반환한다.

## 안전 경계

- 일반 업무는 기존 `Research + Strategy → Chief → Reviewer` 흐름을 그대로 사용한다.
- Marketing과 Legal은 명시적 명령일 때만 기존 흐름에 추가된다.
- Marketing은 초안만 만든다. 게시, 광고 구매, 고객 연락은 실행하지 않는다.
- Legal은 위험 식별을 위한 예비 검토이며 법률 자문이나 최종 결론이 아니다.
- 외부·파괴적·유료·고객 접점 행동은 기존 승인 요청 정책을 계속 적용한다.
- 브리핑은 읽기 전용이며 OpenAI API를 호출하지 않는다.

## 이번에 자동 검증한 항목

- 기존 V0.4 네 에이전트 정의가 변경되지 않고 새 Registry에 포함되는지
- 명시적 명령만 전문 워크플로를 선택하는지
- 마케팅·법률 결과와 선택된 워크플로가 실행 산출물에 기록되는지
- 브리핑의 업무 상태·승인 대기 집계와 KST 표시
- Telegram 브리핑 응답과 전문 명령 업무 접수
- 전체 회귀 테스트, Ruff lint, Ruff format

## 아직 실제 환경에서 확인할 항목

- Render 자동 배포 완료와 `/briefing` 실제 Telegram 응답
- Marketing/Legal 실제 OpenAI 응답 품질과 Reviewer 판정
- 매일 오전 7시 자동 발송 스케줄은 이번 범위에 포함하지 않았다. 수동 `/briefing` 안정성을
  확인한 뒤 별도 배포 설정으로 활성화한다.
